# Rafiki Farm

**Quality Livestock. Better Farming.**

Modern Next.js website for Rafiki Farm (Kenya) with WhatsApp-first conversion, livestock catalogue, farm products, training, blog, gallery, and contact.

## Repo

https://github.com/Levy254885/rafiki-farm

## Quick start

```bash
npm install
npm run dev
```

Copy `.env.local.example` to `.env.local` and fill Firebase / Cloudinary values when ready.

## What's included

- Public pages: Home, About, Livestock (+ detail), Products (+ detail), Nutrition, Training, Blog, Gallery, Contact, Search
- Seed data for demo livestock, products, blog, training, gallery
- WhatsApp enquiry links (configurable number)
- Standalone `index.html` demo with localStorage admin (Ctrl+Shift+A)

## Stack

Next.js · TypeScript · Tailwind CSS · Firebase · Cloudinary · Vercel

Demo admin (HTML version): `admin@rafikifarm.co.ke` / `rafiki123`
